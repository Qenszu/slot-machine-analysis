## 📌 About

This project is a stochastic simulator and ML analyzer for slot machine 
mechanics, built to explore RNG distributions and player behavior patterns.

---

## 🛠️ Technologies

- Python
- NumPy
- PyTorch
- Scipy / Stats
- Plotly / Dash
- SQL Database
- LSTM / Isolation Forest
- Jupyter Notebook

---

## 🎯 Goals

Project will try to predict how long each player session will be, which 
gives information about how good the game actually is and answers the 
question if the game is even profitable.

The results will be an interactive visualization of distributions, 
model metrics and simulations for different RTP parameters.
